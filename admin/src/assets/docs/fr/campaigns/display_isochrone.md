**Comment et pourquoi afficher l'isochrone**

Une isochrone est une carte représentant les lieux accessibles, depuis un point de départ, avec certains modes, dans un temps imparti. Dans le tableau de paramétrage de la campagne, une isochrone depuis le lieu de travail montre les lieux et points d'intérêts accessibles avec différents modes de transport, vous permettant de visualiser notamment jusqu'où les collaborateur·trice·s peuvent se rendre depuis ce lieu de travail.
