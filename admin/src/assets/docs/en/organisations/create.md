## Creating an Organisation Entry

To create a new organisation, administrators need to provide essential information about the organisation and configure mobility-related settings.

### Required Fields

- **Name** (_required_): The organisation's name as it will appear throughout the system
- **Administrators** (_required_): Email addresses of users who will have administrative access to this organisation's data

### Optional Fields

- **Contact Name**: Name of the primary mobility contact person within the organisation
- **Contact Email**: Email address for the mobility contact (must be a valid email format). This address will be displayed to the collaborators at the end of the survey
- **Information URL**: A link to more information about the organisation's mobility options (must start with http:// or https://)
